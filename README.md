# 差异化剧名剧封

NetShort 后台高保真原型：短剧「差异化剧名 / 剧封」从配置到生产的完整链路演示。

**在线访问：<https://yangzeshu.github.io/drama-name-cover/>**

打开即是【剧本库】页面，无需登录、无需安装。

## 页面清单

| 页面 | 说明 |
|---|---|
| 剧本库 | 短剧库列表、差异化剧名剧封配置入口 |
| 工单系统 | 工单列表、新建工单、制作内容差异化详情 |
| 短剧分端管理 | 剧名 / 剧封的分端同步管理 |
| 本地化车间 | 剧名套本地化（列表交互 / 工作台交互） |
| 海报制作车间 | 海报制作（列表视图 / 主从视图）、批量 AI 生成 |

## 说明

- 纯静态 HTML，单文件自包含，无外部依赖
- 全部为演示数据，不含真实业务数据
- 修改后推送 `main` 分支，1 分钟内线上自动生效，访问链接不变
